# Installation

Use [README.md](README.md) as the current installation and local development guide. It covers workspace install, per-app `.env.local` files, both dev servers, TypeScript/lint/build commands, and current Supabase limitations.

Do not follow older instructions that install packages separately in each app, run `disable_rls_for_dev.sql`, use shared demo passwords, or assume a fixed OTP. Those steps are obsolete and unsafe. See [Supabase setup notes](SUPABASE_SETUP.md) before configuring a project.
